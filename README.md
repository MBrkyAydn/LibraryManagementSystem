# Library Management System

A console-based library management system developed in Java. The project was created to practice object-oriented programming concepts while implementing book and member management, borrowing operations, generic structures, Java Stream API, and exception handling.

## Features

### Book Management

- Add books
- Remove books
- Find a book by ID
- Search books by title
- List all books

### Member Management

- Add members
- Remove members
- Find a member by ID
- List all members

### Borrowing Operations

- Borrow books
- Return books
- View borrowed books for each member

### Stream API

- Search books by title
- Filter available books
- Sort books
- Count, AnyMatch and FindFirst operations

### Exception Handling

- BookNotFoundException
- MemberNotFoundException
- BookAlreadyExistException
- MemberAlreadyExistException
- BookAlreadyBorrowedException

## Technologies

- Java
